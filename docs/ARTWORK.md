Browse the [visual image gallery in README](../README.md#image-gallery). It links to all **22 images currently uploaded** to the repository with previews and direct file URLs.

## Organization
Images are categorized in the README as **Main logos**, **Bot avatars**, **Welcome banners and TV artwork**, **Pricing**, **Promotions**, and **Concept boards and drafts**. The actual PNG files currently remain at the root of the repository, retaining their existing URLs.

## Preferred directions
- **TV emblem:** blue-and-gold pirate ship, skull-and-crossbones sail, dark ocean.
- **Cinema:** matching nautical and cinematic brand without simply attaching a film reel to the TV image.
- **Bot avatar:** `neon_gold_pirate_robot_emblem.png` (robotic pirate with no wording).
- **Welcome banner:** `blackwave_tv_welcome_aboard.png` (single-ship direction).

## Review notes
- Older welcomes with duplicate **BlackWave TV** text or too many ships were rejected.
- Previous pricing graphics included text problems. Verify their prices against [PRICING.md](PRICING.md) and inspect images before publishing.
- Older sales and trial advertisements do not establish an active offer.
- The branding board is for ideas, not a single Discord upload.

## Using images in other project chats
Specify the GitHub repository and the exact linked image filename from the README gallery. The repo is private, so the connected account must have access. Never place credentials or customer records in public graphics.
