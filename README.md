## Usage notes
- Prefer the **text-free pirate robot** for a bot avatar.
- Prefer the latest **Welcome Aboard** direction with one ship and one BlackWave TV title.
- Confirm prices against [docs/PRICING.md](docs/PRICING.md), not old price artwork.
- Expired sale artwork must not be reposted as an active offer without revising the date and terms.
- Never commit IPTV credentials, customer data, tokens, private server URLs, or payment details.
