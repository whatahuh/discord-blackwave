## Visual files
Keep individually named, approved images in the ChatGPT **IPTV Project files**, rather than relying on a bundled ZIP archive or a planned GitHub assets/images directory. Project files can be referenced by other chats within the same project. This repository holds written brand guidance and Discord documentation.

Do not commit customer information, API tokens, passwords, private playlist URLs or other secrets.
